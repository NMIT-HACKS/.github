## 🚀 About

**NMIT Hacks** is a nationwide community of student innovators, connecting builders from top institutions with industry mentors. Hands-on workshops, curated challenges, judged tracks and prizes that help projects move forward.

> 🎓 Beginners and veterans welcome. Solo or team. Any discipline. **No entry fee.**
